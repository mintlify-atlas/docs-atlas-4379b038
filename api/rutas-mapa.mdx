The **Rutas Mapa API** is an `[ApiController]` mounted at `[Route("api/rutas-mapa")]`. It backs the **"Armar ruta"** modal that opens from the *Rutas del día* dashboard — the primary interface for building a day's delivery route. All route objects live in an in-memory singleton store (`RutaRepositoryEnMemoria`) until a database integration is wired up, so data is lost on application restart. New routes receive IDs starting at **3001** (the internal counter is seeded at 3000 and incremented atomically via `Interlocked.Increment`).

<Note>
  This controller uses constructor-injected `IRutaRepository` and `ILogger<RutasMapaController>`. No authentication attribute is declared on the controller itself — access is gated upstream by the MVC session layer. All responses follow standard HTTP semantics.
</Note>

<Note>
  A demo route with `rutaId: 1001` is pre-loaded by `RutaRepositoryEnMemoria` at startup. It contains four stops (Polanco, Santa Fe, Coyoacán, Xochimilco) and can be used to test `GET /api/rutas-mapa/1001` without first creating a route via `POST`.
</Note>

## GET /api/rutas-mapa

Returns every route currently held in the in-memory store.

<Tabs>
  <Tab title="Request">
    No path parameters, query parameters, or request body required.

    ```http
    GET /api/rutas-mapa HTTP/1.1
    Accept: application/json
    ```
  </Tab>
  <Tab title="Response 200">
    Returns an array of `RutaLogisticaRequest` objects. The array is empty `[]` when no routes have been created in the current process lifetime.

    ```json
    [
      {
        "rutaId": 1001,
        "origen": { "lat": 19.385040239423045, "lng": -99.17442104933885 },
        "zona": "Centro",
        "vehiculo": "Unidad 102",
        "operador": "María García",
        "prioridad": "Media",
        "fechaRuta": "2026-07-09T00:00:00",
        "distanciaKm": 0,
        "tiempoEstimadoMin": 0,
        "fechaCreacion": "2026-07-09T08:15:00",
        "generadaPorIA": false,
        "destinos": [
          {
            "id": 1,
            "nombre": "Polanco",
            "cliente": "Cliente Demo 1",
            "lat": 19.433,
            "lng": -99.2,
            "activo": true,
            "fecha": "2026-07-09",
            "hora": "09:00",
            "reprogramado": false,
            "ordenSugerido": null
          }
        ]
      }
    ]
    ```

    <ResponseField name="[].rutaId" type="integer">
      Auto-assigned identifier generated by `IRutaRepository.GuardarNueva`.
    </ResponseField>
    <ResponseField name="[].origen" type="object">
      Geographic origin of the route (warehouse / departure point).
      <Expandable title="PuntoGeografico fields">
        <ResponseField name="lat" type="number">Latitude in decimal degrees.</ResponseField>
        <ResponseField name="lng" type="number">Longitude in decimal degrees.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="[].zona" type="string">Delivery zone label (e.g. `"Centro"`, `"Norte"`).</ResponseField>
    <ResponseField name="[].vehiculo" type="string">Vehicle name or unit code assigned to the route.</ResponseField>
    <ResponseField name="[].operador" type="string">Full name of the driver assigned to the route.</ResponseField>
    <ResponseField name="[].prioridad" type="string">Route priority: `"Alta"`, `"Media"`, or `"Baja"`.</ResponseField>
    <ResponseField name="[].fechaRuta" type="string (ISO 8601)">Scheduled date of the route. Nullable.</ResponseField>
    <ResponseField name="[].distanciaKm" type="number">Total calculated route distance in kilometers.</ResponseField>
    <ResponseField name="[].tiempoEstimadoMin" type="number">Estimated travel time in minutes, calculated by Google DirectionsService in the browser.</ResponseField>
    <ResponseField name="[].fechaCreacion" type="string (ISO 8601)">Server timestamp when the route object was constructed (defaults to `DateTime.Now`).</ResponseField>
    <ResponseField name="[].generadaPorIA" type="boolean">
      `true` when the stop order was produced by the "Sugerir ruta" AI stub. Always `false` until the AI engine is connected.
    </ResponseField>
    <ResponseField name="[].destinos" type="array of DestinoLogistico">
      Ordered list of delivery stops included in this route. See the [DestinoLogistico model](/api/models/destino-logistico) for field descriptions.
    </ResponseField>
  </Tab>
</Tabs>

## GET /api/rutas-mapa/\{rutaId\}

Retrieves a single route by its numeric identifier.

<Tabs>
  <Tab title="Request">
    ```http
    GET /api/rutas-mapa/1001 HTTP/1.1
    Accept: application/json
    ```

    <ParamField path="rutaId" type="integer" required>
      The integer ID of the route to retrieve. The route ID is constrained to `int` via the `{rutaId:int}` route template. Use `1001` to fetch the pre-loaded demo fixture without first creating a route.
    </ParamField>
  </Tab>
  <Tab title="Response 200">
    Returns the matching `RutaLogisticaRequest` object (same schema as the array items above).

    ```json
    {
      "rutaId": 1001,
      "origen": { "lat": 19.385040239423045, "lng": -99.17442104933885 },
      "zona": "Centro",
      "vehiculo": "Unidad 102",
      "operador": "María García",
      "prioridad": "Media",
      "fechaRuta": "2026-07-09T00:00:00",
      "distanciaKm": 0,
      "tiempoEstimadoMin": 0,
      "fechaCreacion": "2026-07-09T08:15:00",
      "generadaPorIA": false,
      "destinos": [
        {
          "id": 1,
          "nombre": "Polanco",
          "cliente": "Cliente Demo 1",
          "lat": 19.433,
          "lng": -99.2,
          "activo": true,
          "fecha": "2026-07-09",
          "hora": "09:00",
          "reprogramado": false,
          "ordenSugerido": null
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Response 404">
    Returned when no route with the given `rutaId` exists in memory.

    ```json
    {
      "mensaje": "No existe la ruta 42."
    }
    ```

    <ResponseField name="mensaje" type="string">
      Human-readable explanation of the 404, including the requested `rutaId`.
    </ResponseField>
  </Tab>
</Tabs>

## POST /api/rutas-mapa

Saves a newly assembled route — triggered by the **"Crear ruta"** button in the *Armar ruta* modal. The browser pre-calculates distance and travel time using Google `DirectionsService` before submitting; the server stores those values verbatim.

<Note>
  The route is persisted exclusively in the in-memory `RutaRepositoryEnMemoria` singleton. Restarting the application clears all stored routes.
</Note>

<Tabs>
  <Tab title="Request">
    ```http
    POST /api/rutas-mapa HTTP/1.1
    Content-Type: application/json
    ```

    ```json
    {
      "rutaId": 0,
      "origen": { "lat": 19.384948, "lng": -99.174292 },
      "zona": "Centro",
      "vehiculo": "Unidad 102",
      "operador": "María García",
      "prioridad": "Media",
      "fechaRuta": "2026-07-09T00:00:00",
      "distanciaKm": 12.4,
      "tiempoEstimadoMin": 35,
      "generadaPorIA": false,
      "destinos": [
        {
          "id": 1,
          "nombre": "Polanco",
          "cliente": "Grupo ABC",
          "lat": 19.433,
          "lng": -99.2,
          "activo": true,
          "fecha": "2026-07-09",
          "hora": "09:00",
          "reprogramado": false
        }
      ]
    }
    ```

    <ParamField body="rutaId" type="integer">
      Send `0` — the repository assigns the real ID and returns it in the response.
    </ParamField>
    <ParamField body="origen" type="object" required>
      Geographic coordinates of the departure point (usually the warehouse).
      <Expandable title="PuntoGeografico fields">
        <ParamField body="lat" type="number" required>Latitude in decimal degrees.</ParamField>
        <ParamField body="lng" type="number" required>Longitude in decimal degrees.</ParamField>
      </Expandable>
    </ParamField>
    <ParamField body="zona" type="string">
      Delivery zone label inherited from the selected row in *Rutas del día*.
    </ParamField>
    <ParamField body="vehiculo" type="string">
      Vehicle unit name or code.
    </ParamField>
    <ParamField body="operador" type="string">
      Full name of the assigned driver.
    </ParamField>
    <ParamField body="prioridad" type="string">
      `"Alta"`, `"Media"` (default), or `"Baja"`.
    </ParamField>
    <ParamField body="fechaRuta" type="string (ISO 8601)">
      Scheduled delivery date. Nullable.
    </ParamField>
    <ParamField body="distanciaKm" type="number">
      Total route distance in km, calculated client-side by DirectionsService.
    </ParamField>
    <ParamField body="tiempoEstimadoMin" type="number">
      Estimated travel duration in minutes, calculated client-side.
    </ParamField>
    <ParamField body="generadaPorIA" type="boolean">
      `true` when stop order was produced by the AI suggestion stub. Send `false` for manually assembled routes.
    </ParamField>
    <ParamField body="destinos" type="array of DestinoLogistico" required>
      At least one destination is required. Only destinations with `activo: true` should be included; inactive ones are handled via reschedule flow.
      <Expandable title="DestinoLogistico fields">
        <ParamField body="id" type="integer" required>Internal stop identifier.</ParamField>
        <ParamField body="nombre" type="string">Neighborhood or stop label (e.g. `"Polanco"`).</ParamField>
        <ParamField body="cliente" type="string">Client name for this stop.</ParamField>
        <ParamField body="lat" type="number" required>Stop latitude.</ParamField>
        <ParamField body="lng" type="number" required>Stop longitude.</ParamField>
        <ParamField body="activo" type="boolean">Whether the stop is included in the route calculation. Defaults to `true`.</ParamField>
        <ParamField body="fecha" type="string">Scheduled delivery date for this stop (`yyyy-MM-dd`).</ParamField>
        <ParamField body="hora" type="string">Scheduled delivery time for this stop (`HH:mm`).</ParamField>
        <ParamField body="reprogramado" type="boolean">Set to `true` if this stop was excluded from the route and rescheduled. Defaults to `false`.</ParamField>
        <ParamField body="ordenSugerido" type="integer | null">AI-suggested sequence position. `null` for manually ordered routes.</ParamField>
      </Expandable>
    </ParamField>
  </Tab>
  <Tab title="Response 201">
    Returns the saved route with its server-assigned `rutaId`. The `Location` header points to `GET /api/rutas-mapa/{rutaId}`.

    ```json
    {
      "rutaId": 3001,
      "origen": { "lat": 19.384948, "lng": -99.174292 },
      "zona": "Centro",
      "vehiculo": "Unidad 102",
      "operador": "María García",
      "prioridad": "Media",
      "fechaRuta": "2026-07-09T00:00:00",
      "distanciaKm": 12.4,
      "tiempoEstimadoMin": 35,
      "fechaCreacion": "2026-07-09T08:22:11",
      "generadaPorIA": false,
      "destinos": [
        {
          "id": 1,
          "nombre": "Polanco",
          "cliente": "Grupo ABC",
          "lat": 19.433,
          "lng": -99.2,
          "activo": true,
          "fecha": "2026-07-09",
          "hora": "09:00",
          "reprogramado": false,
          "ordenSugerido": null
        }
      ]
    }
    ```

    <ResponseField name="rutaId" type="integer">
      The auto-assigned route ID, generated by `Interlocked.Increment` from an internal counter seeded at 3000 — so the first route created in a process run receives ID **3001**. Use this value to call `GET /api/rutas-mapa/{rutaId}`.
    </ResponseField>
    <ResponseField name="fechaCreacion" type="string (ISO 8601)">
      Server-side timestamp set automatically by the model constructor (`DateTime.Now`).
    </ResponseField>
  </Tab>
  <Tab title="Response 400">
    Returned when the body fails model validation or when `destinos` is empty or null.

    ```json
    { "mensaje": "La ruta debe incluir al menos un destino seleccionado." }
    ```
  </Tab>
</Tabs>

## POST /api/rutas-mapa/sugerir

Stub endpoint for the **"Sugerir ruta"** AI button. The contract is fully wired end-to-end so that the browser front-end requires no changes when the real AI engine is connected — only the server-side method body will change.

<Info>
  This endpoint currently returns a static response with `disponible: false`. No machine-learning model, external API, or optimization algorithm is invoked. It is intentionally left as a stub to validate the integration pipeline.
</Info>

<Tabs>
  <Tab title="Request">
    ```http
    POST /api/rutas-mapa/sugerir HTTP/1.1
    Content-Type: application/json
    ```

    ```json
    {
      "zona": "Norte",
      "pedidosDisponiblesIds": [101, 102, 105],
      "choferesDisponibles": 2,
      "tipoCamion": "3.5t",
      "cargaEstimadaM3": 8.5
    }
    ```

    <ParamField body="zona" type="string">
      Delivery zone for which the AI should suggest a route (e.g. `"Norte"`, `"Centro"`).
    </ParamField>
    <ParamField body="pedidosDisponiblesIds" type="array of integer">
      IDs of the available orders the AI should sequence into an optimal route.
    </ParamField>
    <ParamField body="choferesDisponibles" type="integer">
      Number of drivers available. Defaults to `1`.
    </ParamField>
    <ParamField body="tipoCamion" type="string | null">
      Vehicle type label (e.g. `"3.5t"`, `"Sprinter"`). Optional.
    </ParamField>
    <ParamField body="cargaEstimadaM3" type="number | null">
      Estimated cargo volume in m³. Optional.
    </ParamField>
  </Tab>
  <Tab title="Response 200">
    Always returns `disponible: false` with an explanatory message until the AI engine is connected.

    ```json
    {
      "disponible": false,
      "mensaje": "La sugerencia de rutas por IA aún no está conectada. Próximamente esta acción consumirá un modelo de lenguaje que, con base en choferes disponibles, tipo de camión y carga, propondrá el orden óptimo de los pedidos seleccionados.",
      "ordenSugerido": null
    }
    ```

    <ResponseField name="disponible" type="boolean">
      Always `false` in the current stub. Will become `true` once the AI engine is connected.
    </ResponseField>
    <ResponseField name="mensaje" type="string">
      Human-readable explanation of the stub status and what the AI will require when enabled: driver count, vehicle type, and estimated cargo volume.
    </ResponseField>
    <ResponseField name="ordenSugerido" type="array of integer | null">
      Will contain the AI-suggested order of `pedidosDisponiblesIds` when the engine is active. Currently always `null`.
    </ResponseField>
  </Tab>
</Tabs>
