Scan4 is the internal logistics platform for **ScanMex**, built on ASP.NET Core 8. It centralises route planning, vehicle and operator assignment, package cubicage calculation, and delivery tracking in a single web application connected to your SQL Server and SAP Business One data.

## Getting started

<Steps>
  <Step title="Clone the repository and restore dependencies">
    ```bash
    git clone https://github.com/aloncm/scan4.git
    cd scan4
    dotnet restore
    ```
  </Step>
  <Step title="Configure your database connection and Google Maps key">
    Store secrets with the .NET User Secrets manager — never commit credentials to source control.
    ```bash
    dotnet user-secrets set "ConnectionStrings:SqlCon" "<base64-encoded-connection-string>"
    dotnet user-secrets set "GoogleMaps:ApiKey" "<base64-encoded-api-key>"
    ```
    See the [Configuration guide](/configuration) for the full setup.
  </Step>
  <Step title="Run the application">
    ```bash
    dotnet run
    ```
    Navigate to `https://localhost:5001` and log in with an account that exists in your `SMX_OHEM` table.
  </Step>
  <Step title="Explore the modules">
    After login you are redirected to the first module your role has access to. Administrators land on the Dashboard; other roles land on their first permitted module.
  </Step>
</Steps>
